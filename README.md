# 古籍数字化识别质量放行服务

本服务为古籍数字化团队提供批次建档、页面证据登记、OCR 质量门禁、问题整改、专家复核、证据冻结和发布凭据验真能力。服务通过本地 SQLite 保存业务数据和审计事件，使用哈希链保证状态变化可复核。

标准运行方式：

```text
go run . -addr=127.0.0.1:19081
```

也可设置 `PORT` 环境变量，服务会绑定 `127.0.0.1:<PORT>`。运行自检：

```text
go run . -addr=127.0.0.1:19081 -selfcheck
```

测试命令：

```text
go test ./...
```
